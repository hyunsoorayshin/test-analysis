# test-analysis

Two small Python scripts that turn weekly class score sheets (one CSV per class) into per-student charts:

- `step1_line_chart.py` draws one PNG per student with a subplot per subject, each showing the raw weekly scores and a smoothed trend curve.
- `step2_annotate.py` draws one PNG per student per subject and marks every week where the score moved by 15 points or more from the previous week, with a short feedback note under the chart.

Both scripts read every CSV in a folder, work out each student's current class from the most recent date, follow students who moved between classes, and only produce charts for students who are still present in the latest week.

## Why I built it

I was teaching at an English academy in Seoul. Before each monthly review I wanted to see every student's trajectory in every subject at a glance, and I wanted sudden drops or jumps flagged automatically so I would not miss them while flipping through score sheets. I wrote these scripts independently, on my own time, to do exactly that.

## What this is not

- This is **not** official infrastructure of any school or academy and was **not** an assigned work product.
- The repository contains **no real student data**. Everything under `sample_data/` is synthetic, generated by `make_sample_data.py` with a fixed random seed. Names like `StudentA 학생A` and the scores next to them are made up.

## How the analysis works (plain answer)

- **Trend curves** are ordinary polynomial least-squares fits (`numpy.polyfit`, degree up to 3, lower when a student has fewer points). They exist for visual smoothing only; they are not forecasts and nothing is trained.
- **"Significant change" flags** come from a single hand-set threshold: `CHANGE_THRESHOLD = 15` in `step2_annotate.py`. A week is flagged when the score differs from the previous recorded score for that subject by 15 points or more. Blank weeks are skipped, so the comparison is always against the last week that has a score.
- The feedback text ("good gain", "needs attention", ...) is picked from fixed bands on the size of that change. There is no model, no prediction, and no statistics beyond the polynomial fit.

## How to run

Tested with Python 3.9 on macOS.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python make_sample_data.py      # regenerates sample_data/*.csv (optional, already committed)
python step1_line_chart.py      # -> charts/<class>/<student>.png
python step2_annotate.py        # -> charts_annotated/<class>/<student>/<student>_<subject>_final.png
```

Both chart scripts accept the same options:

```
--csv-dir DIR     folder with one CSV per class (default: sample_data/ next to the script)
--out-dir DIR     where to write PNGs (default: charts/ or charts_annotated/ next to the script)
--pattern GLOB    which files inside --csv-dir to read (default: *.csv)
```

The class code is taken from the CSV file name (`A1.csv` becomes class `A1`).

### Input format

Each CSV has a header row and then one row per student per date:

```
Date,Name,Vocabulary,Grammar HW,Grammar Speaking,Science HW,Science Test,Science Textbook,Reading,Grammar Test,Speaking,Novel
```

- `Date` is `M/D/YY`, for example `1/2/26`.
- `Name` is `English 한글` (an English name, a space, a Korean name). It is used as-is for matching across files and, with spaces replaced by underscores, for output file names.
- Any row whose `Name` starts with `*` is a reference row and is ignored.
- Only `Vocabulary`, `Science HW`, `Science Test`, `Reading`, `Grammar Test` and `Novel` are charted; the other columns are carried through untouched. Blank cells are allowed.

### Fonts

Student names contain Hangul. The scripts look for a Korean-capable font (Apple SD Gothic Neo, AppleGothic, Noto Sans CJK KR, Noto Sans KR, NanumGothic or Malgun Gothic) and use the first one installed as a fallback. If none is found the charts still render, but the Korean half of each name shows as boxes.

## Layout

```
test-analysis/
├── step1_line_chart.py     one chart per student, subplot per subject
├── step2_annotate.py       one chart per student per subject, with change flags
├── make_sample_data.py     seeded generator for the synthetic CSVs
├── sample_data/            A1.csv .. A4.csv (synthetic)
├── requirements.txt
├── LICENSE
└── README.md
```

`charts/` and `charts_annotated/` are created when you run the scripts and are ignored by git.
